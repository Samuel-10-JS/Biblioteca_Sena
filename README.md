# Sistema de Biblioteca - Proyecto de Consola en C# (EV06)

Proyecto de consola desarrollado en C# .NET aplicando sintaxis básica, funciones estáticas, estructuras de control, validaciones simples y Git Flow, sin POO avanzada, colecciones reales ni persistencia real (simulado por consola).

## Estructura del Git Flow
- `main` / `master`: Rama de producción / estable.
- `develop`: Rama de integración para los módulos (features).
- `feature/*`: Ramas de desarrollo por cada módulo del sistema.
